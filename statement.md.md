# Project Statement

## Rock-Paper-Scissors Game

This project is a simple **Rock-Paper-Scissors game developed using Python**. I created this project to understand and practice the basic concepts of Python programming in a simple and enjoyable way.

The game allows the user to choose between **Rock, Paper, and Scissors**, while the computer randomly selects one of the three options. The program then compares both choices and decides whether the user wins, the computer wins, or the round ends in a tie.

While making this project, I used concepts such as **lists, loops, conditional statements, user input, exception handling, and the `random` module**. I also added input validation so that the program can handle invalid choices instead of stopping unexpectedly.

One of the main reasons for choosing this project was that Rock-Paper-Scissors is a simple game, but it still provides a good way to understand how programming logic works. It helped me see how different conditions can be combined to make decisions inside a program.

The program also gives the user an option to play multiple rounds. After each round, the user can decide whether they want to continue or exit the game.

Overall, this project helped me strengthen my understanding of basic Python programming and gave me practical experience in turning a simple idea into a working program.
